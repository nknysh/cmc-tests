# APP-05: Unknown address shows not found

**As a** user who followed a broken or mistyped link
**I want** to be told the page doesn't exist
**so that** I can find my way back.

## Acceptance criteria

- An address that matches no section shows "Page not found". `AC-1`
- It explains: "There's nothing at this address." `AC-2`
- A "Back to all coins" link opens the Markets page. `AC-3`
- The header, main navigation and footer are still shown (APP-01). `AC-4`
- An unknown coin address shows COIN-05 instead of this page. `AC-5`
